# Verification boundaries

Current portable-core evidence:

- `tests/core.sh` passes native ASan/UBSan contract tests, the C11 ABI consumer, standalone host/replica example and wasm32 ABI checks. Contracts cover invalid configuration, authority, input validation, small buffers, malformed/truncated and stale packets, atomic snapshot application, modular sequence wrap, queue capacity and handle-pool exhaustion.
- Native and import-free Wasm outputs match **every message byte** across the tested 600-tick host/replica trace (35,200 bytes), plus final state: host tick 600, dummy HP 0 on both views, guest x=667952 milli-pixels. A 32-bit summary hash is diagnostic only; the test also directly compares the full trace. This bounded test is not a general deterministic-lockstep proof.
- A Linux CMake Debug build passes three CTest cases: core contract, C consumer and standalone replication. `nm` shows only versioned `ec_v1_*` core exports. The prepared native core links the platform C runtime; no C++ standard library is needed by that build. The Wasm test verifies zero imports and copies a typed ABI view into caller-owned module memory.
- `tests/native_adapter.gd` calls the actual Godot GDExtension bridge and confirms one C++ fixed tick moves host x from 180000 to 182833 milli-pixels. Godot import/script loading and the Web export pass.
- `tests/network.sh` passes two independent native Godot processes through C++ input/snapshot messages and replicated combat. No engine dictionaries carry authoritative state over the network.
- `tests/lab.sh` passes two independent GPU-rendered Godot workers, each with its own C++ handle, both keyboard schemes and 50 ms application delay each way. Guest attacks reduce the shared dummy to HP 0 on host and replica; measured RTT and snapshot reception are present. Renderer logs select NVIDIA RTX 2080 Ti. Viewport captures show automatic character animation and debug HUD. These are loopback tests, not internet measurements.
- `tests/web.sh` loads the actual Godot export in Chromium under headless Gamescope, verifies a live Wasm core handle/calls, clicks Play solo and injects real keyboard input. Core view tick advanced 15→57 and x advanced 180000→298986 in one smoke test. Onboarding/gameplay screenshots are inspected at 960×540; no mobile/full-browser matrix is claimed.

Unity/Unreal/custom-engine guidance is not adapter implementation evidence. Other OS/architectures are not tested. Browser co-op remains unverified: the earlier manual SDP/ICE test returned zero candidates in both Godot and a plain RTCPeerConnection probe. No signaling or TURN relay has been deployed. The current Pages deployment was also checked: hosted HTML, portable Wasm, JS bridge and PCK SHA-256 values match the local candidate, and the same real-keyboard Chromium/Wasm smoke test passes at https://rareskey.github.io/coop-side-scroller/. Future deployments should repeat these checks.
