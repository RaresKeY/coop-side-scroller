# Prototype contract

`src/main.gd` owns the scene, onboarding/menu controls, a single-screen 960-pixel arena and shared training dummy. Floor contact is a scalar simulation at y=448; the level uses a repeated 32×32 CraftPix prototype tile. No skyline or decorative scene is present. There is no RPG inventory, map system, platform collision system or audio.

During play, only Menu, connection status and movement instructions are shown. Play solo / Host game / Join game and native address entry live in the menu. Browser connection codes appear during host/join setup. Open setup panels suppress gameplay input. No animation selection buttons or dropdown exist. Character clips are chosen automatically: idle, run, jump and attack. The imported walk/hurt/death sheets are retained for later gameplay states; no preview UI exists. Sheets use 128×128 AtlasTexture regions, nearest filtering with mipmaps and 2× scale. The import metadata excludes effect-only tail cells with fewer than 200 alpha pixels. Attack uses the source sheet’s 111-pixel foot baseline and restarts on a replicated attack ID so held attacks do not freeze on an empty tail frame. Public source runs with an original fallback character if private art is absent.

Host simulates at 60 Hz, including guest movement, gravity, attack cooldown, range/facing checks and enemy HP. Guest sends bounded axis and held jump/attack flags on unreliable ordered channel 1. Input older than 300 ms neutralizes on host. Host transmits complete actor dictionaries, dummy HP/x and snapshot sequence every third physics frame on channel 2. Guest displays snapshots directly without interpolation/prediction. RPC authority restricts snapshots to host and accepts inputs only from a known connected player. Ping/pong measures application RTT in milliseconds. Lab delay queues bound outgoing packets to 256 entries.

Native transport: ENet UDP 27840 by default, one guest; lab local pairs select an ephemeral port. Web transport: WebRTCMultiplayerPeer, host ID 1 / guest ID 2. Manual base64 JSON codes contain SDP and gathered ICE; two additional ordered channels match RPC channel IDs. Empty ICE gathering reports an explicit failure. Browser clipboard controls and editable text support code exchange. STUN uses public Google STUN; no TURN or automatic signaling is configured. Browser WebRTC is unverified end to end. Reset closes the old peer, clears queued packets and actors/sprites. Client failure, host departure and timeouts return to solo.

`--test-host` / `--test-client` are finite native integration modes. `--capture` saves a finite native gameplay preview. See [network lab](network-lab.md) for interactive independent-process testing and [verification](verification.md) for evidence boundaries.
