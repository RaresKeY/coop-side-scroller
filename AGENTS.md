# Co-op Side Scroller

Read `specs/_readme.md` and `specs/architecture.md` before changes. This is a portable C++ co-op core with a focused single-character Godot web/native reference adapter. Keep implemented contracts in `specs/`, decision rationale/integration guidance in `design/`, evidence in `specs/verification.md` and future work in `BACKLOG.md`. Update the relevant documents when behavior changes; do not append obsolete rollout chronology to current contracts.

Shared rules/authority/messages belong in the engine-independent `core/`, behind `ec_v1_*` C ABI; keep engine APIs, rendering, input capture, clocks and transports in adapters. Read `specs/c-abi.md` and `specs/portable-core.md` before core changes. Never reintroduce a GDScript simulation or manual animation selection.

Explicitly prepare with `python3 tools/build_core.py`; `--check` only checks freshness. Use executable root `./play.sh` through the shared Godot Podman runtime. `tools/build_web.sh` explicitly prepares the single-thread Web export. Normal play does not export. `./play-labs.sh` opens the compact native network chooser; `./play-labs.sh pair` opens separate host/guest processes. See `specs/network-lab.md` for control routing and owned teardown. Keep gameplay UI simple; no animation inspection controls. Automated rendered runs use headless Gamescope, muted/Dummy audio and hardware GPU. `--capture` is finite; native `--test-host` and `--test-client` are finite localhost transport checks.

Public source must exclude `assets/private/`, imported caches and build candidates. CraftPix raw art remains private; the importer and hash manifest are public. Do not add a project license. Publishing must keep playable compiled assets in the static site, separate from source art. Managed Cloudflare TURN is deployed as documented in `specs/turn-service.md`; authenticated automatic signaling is documented in `specs/private-lobbies.md`; self-hosted relay operations remain deferred in BACKLOG.md. Do not deploy additional services without authorization or claim general internet reliability from bounded connection tests.
